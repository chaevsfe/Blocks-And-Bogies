# Create Fly: Blocks & Bogies

Bogie styles for Create's trains: driving wheels up to six axles, trailing trucks, five valve gears and a menu to pick them from.

> [!IMPORTANT]
> **This is an unofficial port.** It is not affiliated with or endorsed by
> Weido's Oddities. 
> Please report problems here.

## Compatibility

| Component | Version |
| --- | --- |
| Minecraft | `26.3` |
| Mod loader | Fabric Loader `0.20.1` or newer |
| Create Fly | `6.0.9-1` or newer |
| Fabric API | required |
| Java | `25` or newer |
| Environments | Client and server |

## Building

```
git clone https://github.com/chaevsfe/Blocks-And-Bogies
cd Blocks-And-Bogies
./gradlew build
```

Requires JDK 25.
